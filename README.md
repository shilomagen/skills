# skills

My public Claude Code skills. Installable as a plugin marketplace:

```
/plugin marketplace add shilomagen/skills
```

## Plugins

| Plugin | Skill | What it does |
|---|---|---|
| [velocity](./velocity) | `/full-cycle` | One prompt from idea to mergeable PRs: plan → grill → adversarial review → tickets → parallel agent implementation → evidence-backed verification → stacked PRs looped to green. |

```
/plugin install velocity@shilo-skills
```

See each plugin's README for the full story and per-repo configuration.
